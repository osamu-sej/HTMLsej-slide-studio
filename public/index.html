    使い方とショートカット

    基本の流れ

    1. 「作成」で素材を入れてテーマを選び「骨子を作る」→ 骨子を整えて「この骨子でスライドを作る」（雛形・取り込み・サンプルからも始められます）
    2. 右の「✦ AIと話す」で直してほしいことを書く。変更は提案として届くので、確認して採用・却下します。「工程をクリックで1つずつ出して」「各カードにクリックで開く補足を付けて」のように動きも頼めます
    3. スライド上の文字をクリックすると、その場で書き換えられます。写真・動画・動き・クリックで開く詳細は「編集」タブで
    4. 「▶ 発表」でそのままZoomなどで画面共有。「HTML出力」で動きごと1つのファイルに書き出せます

    編集のショートカット

    発表中のショートカット

    → Space クリック次へ（「クリックで順番に」のスライドは1項目ずつ、「不足と打ち手」は打ち手を1つずつオン）
    ←前へ
    P発表者ビュー（ノート・次のスライド・経過時間を別ウィンドウに。Zoomでは発表のウィンドウだけを共有）
    N / O（G） / Fノート / スライド一覧 / 全画面
    D自動デモ（矢印が各ページを順に操作して見せ、一覧で終わる。キーかクリックで止まる）
    B / W画面を黒 / 白にする
    番号 + Enterそのスライドへ移動
    Esc詳細・根拠パネルを閉じる／発表を終了

    知っておくと便利

    • 赤い破線の枠は、文字がスライドに収まっていない箇所です。欄を短くするか「AIで収まるように直す」を使います
    • アップロードした動画はこのブラウザの中に保存されます。HTML出力するとファイルの中に入ります（大きな動画はファイルも大きくなります）
    • Zoomで動画の音を流すときは、画面共有の「音声を共有」をオンにしてください
    • 作業中の資料はこのブラウザに自動保存されます。別のPCへ移すときは「その他」→「JSONで保存」
