# HTML SEJ Slide Studio

AIで構成したスライドを、**SEJの原本テンプレートの見た目**のまま、**動きのあるHTMLプレゼンテーション**として編集・発表・書き出しするWebアプリです。
伝えたいことや元資料を入れると、AI（Codex）が骨子を出し、整えてからスライドにします。仕上げはAIとの会話と、スライド上での直接編集。**PowerPointのようなリボンで図形・テキストボックス・画像・アイコン・線を置いて**、AIの案を人の手で作り込むことも、白紙から作りきることもできます。そのままZoomなどで画面共有して発表し、動きごと1つのHTMLファイルに書き出せます。

## 2つのスタジオの合体

[HTML Slide Studio](https://github.com/osamu-sej/HTML-slide-studio)（HTMLで描くスライドエンジン・動き・発表・書き出し）をベースに、[SEJ Slide Studio](https://github.com/osamu-sej/sej-slide-studio)（SEJ原本テンプレート・ブランド検査・デザインキット）のテンプレートをHTMLで再現しました。PowerPoint（.pptx）は作らず、スライドはすべてHTMLです。

| | HTML Slide Studio から | SEJ Slide Studio から |
|---|---|---|
| スライド | 1920×1080のHTMLエンジン、44レイアウト、SVGグラフ、文字の自動調整 | 原本テンプレート（`assets/sej/template.pptx`）のマスター・安全領域・文字サイズの考え方 |
| 見た目 | エンジンの8つのテーマ（撮影テスト用に残すだけで、スタジオでは選べません） | **SEJテンプレート（固定）**：ロゴ・緑線・「秘（B）」「社内限り」・スローガン・コピーライト・ページ番号、配色（黒／濃紺／グレーの文字、淡青・グレー・淡茶の面） |
| デザイン | 動き（登場・クリックで順に・モーショングラフィック・切り替え）、動く資料、深掘りページ | seven-eleven-pptx のデザインキット（同心円の波紋、淡い大きな章番号、上罫＋グレー番号の列、Before=淡茶／After=淡青、強調の1本だけ濃紺のグラフ、ウォーターフォールの色分け） |
| 品質 | 文字あふれの検出とAIの自動修正、構成チェック | **SEJブランド検査**：白抜き文字・濃い面の上の文字・影・ブランド外の文字色をチェックに表示 |
| AI | 骨子→生成→会話で修正、別案、ノート、画像生成 | SEJ社内資料向けの指示（タイトルは緑線の上の1行、強調は濃紺の1〜2か所、テンプレートが描く要素を本文に書かない） |

## SEJテンプレート

「SEJ」テーマは、原本テンプレートの2つのマスターを、PowerPointと同じ位置（1インチ＝144px）にHTMLで描きます。位置は `test/test_sej_master.py` が `template.pptx` と1px以内で一致することを確かめています。

| マスター | 使うスライド | 描くもの |
|---|---|---|
| タイトル用 | 表紙・章扉 | 中央の緑線、左上のスローガン、ロゴ、秘（B）、社内限り、コピーライト |
| 本文用 | それ以外（締め・写真・ひと言を含む） | タイトルの下の緑線、右下のスローガン、ロゴ、秘（B）、社内限り、コピーライト、ページ番号 |

- **表紙**：タイトルは緑線の上、日付は線の下の左、資料の対象者（所属）は右。写真を入れるとタイトルの上に横長の帯で入ります。右下から同心円の波紋。
- **章扉**：緑線を地平線に見立て、淡い大きな章番号と章タイトル。波紋は背景としてマスターの下を通ります。
- **本文**：タイトルは緑線の上の1行（はみ出すときは文字を小さくし、それでも入らなければ赤枠で知らせます）。キーメッセージは線の下に太字の一文で、`**語句**` の部分だけ濃紺。本文は安全領域（左0.5インチ、1.12〜6.62インチ）に収めます。
- **締め**：依頼事項を上罫＋大きなグレー番号の列で。表紙の波紋が戻ってきます。
- **全面写真**：写真がマスターを隠さないよう、本文の枠いっぱいに写真を置き、メッセージは白いカードに載せます。
- **HTMLならではの動き**：発表中は波紋がゆっくり広がり、表紙・章扉では同心円が開くように現れます。項目の出し方・切り替え・動く資料など、ほかのテーマの動きはすべてSEJでも使えます。
- **新規資料はSEJテンプレート**：スタジオで新しく作る資料はSEJテンプレートです。テーマやアクセント色を選ぶ画面はなく、AIもデザインを変えません。前の版で別のテーマにした資料や、ほかのテーマのJSONも、開くとSEJテンプレートに戻ります。PowerPointを「見た目どおり」に取り込んだページは元のマスターを保持します。
- **文字**：Meiryo UI（WindowsのPCでは原本と同じ）。Meiryo UI がない環境では BIZ UDPゴシック、スローガンは UD デジタル 教科書体（なければ Klee One）で表示します。
- **ブランド検査**：SEJの資料では、画面上の「チェック」に「SEJブランド」の指摘（白抜き文字・濃い色の面の上の文字・影・黒／濃紺／グレー以外の文字色）が出ます。
- テンプレートの差し替え：`assets/sej/template.pptx`・`brand-profile.json`（SHA-256）・`public/engine/engine.js` の `SEJ_MASTER`／`SEJ_BOX`・`assets/sej/logo.png`／`copyright.png` を同じ変更で更新し、`npm run test:py` で位置を確かめます。

## はじめかた

必要なもの：Node.js 22 以上。既存資料の取り込み・ファイル添付を使うときは Python 3.11 以上。

```bash
npm install
# 取り込み機能を使う場合（任意）
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
npm start
```

ブラウザで http://localhost:8787 を開き、「Codexに接続」を押してChatGPTアカウントでデバイス認証します。表示された認証コードは「コピー」ボタンでコピーできます（APIキーは不要）。
認証中にページを再読み込みしてもコードは再表示されます。コードの期限が切れたら「コードを再発行」を押してください。認証に失敗した場合は理由を表示し、接続をやり直せます。
接続しなくても、雛形・サンプル・JSONの読み込み・編集・発表・書き出しは使えます。

手元で [Ollama](https://ollama.com/) の `gemma4:12b` が動いていれば、Codexが使えないとき（利用上限・接続切れ）に自動で予備AIとして使います。

### 最新版にする

```bash
git checkout main && git pull
npm install
# 動いている npm start を Ctrl+C で止めてから、もう一度
npm start
```

画面はサーバーが起動したときのファイルを配るので、`git pull` のあとは**サーバーの再起動**が必要です。画面左上の版表示にマウスを乗せると、動いているコミットとサーバーの起動時刻が出ます（`/healthz` でも確認できます）。

## 使い方の流れ

1. **作成**：伝えたいことを書くかファイルを添付し、対象・目的・枚数を選んで「骨子を作る」。デザインはいつもSEJテンプレートです。
2. **骨子**：行を書き換え・並べ替え・追加し、「この骨子でスライドを作る」。同じ見た目のスライド（タイムライン・プロセス・ロードマップなど横に並ぶ流れ）が続く骨子はAIが自動で選び直し、手で変えたときも骨子の画面で知らせます。生成後、枠に収まらない文字はAIが自動で短くします。
3. **仕上げ**：右の「✦ AIと話す」で依頼します。例：「工程をクリックで1つずつ出して」「各カードにクリックで開く補足を付けて」「結論を先に並べ替えて」「@5 の数字を目立たせて」。
4. **動き**：ツールバーの「SEJ・動き」で切り替え・登場のしかた・マウスを乗せたときの動き、そしてモーショングラフィック（背景の動き・大きな文字の動き・強調の見せ方）を資料全体で選べます。どれも実際の資料で動くプレビューを見ながら選べます。1枚ごとの動き（中身の出し方・文字・背景・登場・強調・そのスライドへの切り替え）は「編集」タブの「動き」「モーショングラフィック・この1枚の動き」で。
5. **発表**：「▶ 発表」（F5）。Zoomでは発表のウィンドウを画面共有し、`P` で発表者ビューを別ウィンドウに出すと、ノートを見ながら話せます。動画の音を流すときは「音声を共有」をオンにします。
6. **書き出し**：「HTML出力」で1つのHTMLファイルに。相手はブラウザで開くだけで、動きのまま見られます。

### 資料を保存して探す

編集画面の「資料を保存」（または ⌘S / Ctrl+S）で、資料をこのブラウザの保存庫に明示的に保存します。同じ資料を再度保存すると上書きされ、「保存庫」から「編集中の資料を新規保存」を選ぶと別の資料として残せます。編集後に保存し直すまでは、保存庫の内容は変わりません。作業中の自動保存と「履歴」の版は別に維持されます。

「保存庫」の検索は資料名・目的・前提条件に加え、全スライドの本文、表、グラフのラベルと数値、詳細カード、スピーカーノートを対象にします。結果から資料全体を開く、該当スライドを開く、今編集中の資料にその1枚を追加する、の3通りを選べます。複数のキーワードは空白で区切って検索できます。

保存庫とアップロードした写真・動画はこのブラウザの中にあります。ブラウザのデータを消すと失われるため、長期保管や別端末への移動には「JSONで保存」も使ってください。

### 発表中のキー

| キー | 動作 |
|---|---|
| → / Space / クリック | 次へ（「クリックで」のスライドは1項目ずつ、「順に注目」のスライドは次の項目を強調） |
| ← | 前へ |
| 番号 + Enter | そのスライドへ（深掘りページは数えない） |
| 「＋ 詳しく」「＋ 内訳」「＋ 根拠」の付いた所をクリック | 詳細カード・根拠パネルを開く（×・Esc・外側のクリックで閉じる） |
| 切り口のボタン・スライダー・打ち手 | その場で並び替え・計算し直し・オン／オフ（スライドは進まない） |
| 「↗ 深掘り」の付いた項目をクリック | 深掘りページへ |
| P | 発表者ビュー（別ウィンドウ） |
| N / O（G） / F | ノート / 一覧 / 全画面 |
| D | 自動デモ（矢印が各ページを順に操作して見せ、一覧で終わる。キー・クリックで止まる） |
| B / W | 黒い画面 / 白い画面 |
| Ctrl+P / Ctrl+I / Ctrl+L / Ctrl+E / Ctrl+A | ペン / 蛍光ペン / レーザー ポインター / 消しゴム / 矢印に戻す（下のバーの「ペン」からも。書いている間はクリックで進まない） |
| E | スライド上のインクをすべて消す |
| J | 字幕のオン・オフ（話した言葉を字幕で表示。Chrome・Edge） |
| Esc | ペンを置く・詳細カードを閉じる・深掘りページから戻る・発表を終える（発表中に書いたインクは「保持しますか？」でスライドに残せます） |

書き出したHTMLファイルは、アドレスの最後に `#static`（例：`資料.html#static`、`#5-static`）を付けて開くと、動きを止めて全部が組み上がった状態で表示します（操作で変わるページは、打ち手がすべてオンなど見出しの判断が見える状態）。

書き出したHTMLファイルをパソコンから直接開いた場合、YouTubeはその場で再生できない（YouTube側の制限）ため、サムネイルからYouTubeを開く形になります。動画ファイルはそのまま再生されます。

## 編集画面（PowerPointと同じ配置）

編集画面はPowerPointと同じ並びです。上から、リボン（全幅）、1行のメッセージバー、［サムネイル｜スライドとノート｜作業ウィンドウ］、ステータス バー。

- **ファイル**：リボンの左端の「ファイル」で、新規（作成画面へ）・開く（保存庫）・上書き保存（⌘S）・名前を付けて保存・書き出し（HTML・PDF・JSON・レビュー用ファイル）・JSONを読み込む・版の履歴・使い方。
- **リボンの表示オプション**：リボン右上の「表示オプション」で「常にリボンを表示する」「タブのみを表示する」「自動的に非表示にする（全画面表示モード）」を選べます。リボン右下の ˄、タブのダブルクリック、⌘F1（Ctrl+F1）でタブだけに折りたためます。タブだけのときは、タブを押すとリボンがスライドの上に重なって開き、コマンドを選ぶ・スライドをクリックする・Esc で閉じます（📌で固定）。選んだ表示は次に開いたときも同じです。
- **スライドはウィンドウに合わせて全体を表示**：ステータス バーの −／スライダー／＋、倍率（押すと 400%〜33% と「ウィンドウに合わせる」）、⤢（ウィンドウに合わせる）で拡大・縮小できます。⌘＋ホイール（トラックパッドのピンチ）、⌘＋／⌘−、⌘0（ウィンドウに合わせる）も使えます。100% はスライドの実寸（13.33インチ＝1280px）です。
- **ステータス バー**：スライド番号（深掘りページ・非表示スライド・レイアウト・動き）、資料の枚数と対象、チェック（構成の指摘）、SEJ・動き、ノート、動きを確認（閲覧表示）、1枚／一覧／構成、ズーム。
- **ノート**：ステータス バーの「ノート」でスライドの下にノート欄が開き、そのまま入力できます（境目をドラッグで高さを変更）。
- **サムネイルと作業ウィンドウ**：境目をドラッグで幅を変え、サムネイルは細くすると閉じます（「サムネイル」で開く）。作業ウィンドウは » で閉じ、縦に並んだタブを押すと開きます。幅と開閉は記憶します。
- **サムネイルの操作**：右クリックで 切り取り・コピー・貼り付け・新しいスライド・スライドの複製・削除・非表示スライドに設定・レイアウトの変更・このスライドから発表。サムネイルを選んだ状態で Delete（削除）、⌘C／⌘X／⌘V（スライドのコピー・切り取り・貼り付け）、⌘D（複製）、Enter（新しいスライド）。⌘M でどこからでも新しいスライド。
- **ガイド**：表示タブの「ガイド」▾ か、スライドの何もないところの右クリックで、垂直・水平のガイド（点線）を置けます。ドラッグで動かすとスライドの中央からの距離（cm）が出て、スライドの外へ出すと削除、Ctrlを押しながらドラッグでコピー。部品はガイドに吸着します（SEJの本文の領域・中央のガイドにも）。ガイドは資料ごとに保存されます。
- **ルーラーとグレースケール**：表示タブの「ルーラー」でスライドの上と左に目盛り（cm、スライドの中央が0。選んだ部品の範囲に色が付き、マウスの位置に印）。「グレースケール」で白黒の見え方を確かめられます（資料は変わりません）。
- **セクション**：ホームの「セクション」かサムネイルの右クリック「セクションの追加…」で、そのスライドからセクションを始めます。サムネイルとスライド一覧にセクション名が出て、名前を押すと折りたたみ・展開、右クリックで名前の変更・削除（スライドは残る）・上へ／下へ移動・すべて折りたたむ。スライド一覧ではスライドをドラッグで並べ替えられます。
- **コメント**：校閲タブの「新しいコメント」で右の作業ウィンドウ「コメント」に書き込みます（⌘Enterで投稿）。書いた人の名前と日時が付きます（最初の投稿で名前を一度だけ聞き、このブラウザに保存。ファイル → ユーザー名・校閲 → ユーザー名で変更すると自分のコメントの名前も変わります）。返信のスレッド、`@`で相手を指定（名前の候補が出ます。自分宛ては印が付き「自分宛て」で絞り込み）、自分のコメントの編集（編集済み）、解決（解決した人）／もう一度開く、スレッドの削除、校閲 → 削除（このスライド・資料全体）。図形を選んでから付けるとその図形にピン留めされ、スライド上のピン（校閲 → コメントの表示）から開けます。前へ／次へ（コメントのあるスライドへ）・すべてのスライドのコメントを表示。未解決のコメントはサムネイルに 💬 で出ます。PowerPointを見た目どおりに取り込むと元のコメント（書いた人・日時・返信・解決）も残り、レビュー結果は「スライドのコメントにする」でコメントにできます。発表とHTML出力には出ません。
- **共同編集**：上部の「共有」（またはファイル → 共有）で共同編集を始めるとリンクができます。リンクを開いた人と同じ資料を同時に編集でき、変更はすぐ相手に届きます（同じスライドを同時に触っても、別々の部品ならどちらの変更も残ります。スライドの順番・資料のタイトルも同じ）。⌘Zで戻るのは自分の変更だけです。参加者は名前と色で、共有ボタン（人数）・サムネイル（いま見ているスライド）・選んでいる部品の枠に表示され、参加・退出は通知されます。コメントは書いた人の名前つきで、@で相手を指定できます。写真・動画・音声のファイルも部屋を通して相手に届きます。部屋はサーバーのメモリーに置かれ、誰もいないまましばらく経つと閉じます（サーバーが再起動しても、開いていたブラウザの資料から自動で戻ります）。チームのパスコードを設定しているときはメンバーだけが使えます。共有ボタンのメニューから、リンクのコピー・参加者のいるスライドへ移動・共同編集から抜けるができます。
- **図形の結合**：図形を2つ以上選んで（Shift＋クリック）、図形の書式 →「図形の結合」から接合・型抜き/合成・切り出し・重なり抽出・単純型抜き。メニューに乗せると結果がスライドの上にプレビューされます。最初に選んだ図形の書式・文字・アニメーションを引き継ぎ（単純型抜きは最初の図形から残りを抜きます）、穴や離れた部分も1つの図形（頂点の編集で穴の点も動かせます）。⌘Zで戻せます。
- **SmartArt**：挿入 →「SmartArt」で、リスト・手順・循環・階層構造・集合関係・マトリックス・ピラミッドの14レイアウト（プレビュー付き）から選びます。横に出るテキスト ウィンドウで1行1項目（Enterで追加・Tabでレベルを下げる・Shift+Tabで上げる）。項目をダブルクリックするとその行を開きます。「SmartArt のデザイン」タブで図形の追加（後・前・上・下）・箇条書きの追加・レベル上げ/下げ・上へ/下へ移動・右から左・レイアウトの変更・色の変更（淡青・淡茶・グレー・3色・線だけ）・角の形・文字の大きさ・グラフィックのリセット・図形に変換（グループ化した図形と線に）・テキストに変換。ホーム → 段落の「SmartArt に変換」で、選んだテキストを箇条書きのレベルのまま図にできます。アニメーションの効果のオプション「1つずつ」で項目が順番に現れます（おまかせでも付きます）。色はSEJの淡い色だけで、白抜き文字・影は使いません。
- **オーディオ・画面録画**：挿入 →「オーディオ」でこのデバイスの音声・この場での録音・URL、「画面録画」で画面・ウィンドウ・タブ（マイクの音声も）をビデオとして入れます。音声はスライドの中央にスピーカーのアイコンで置かれ、発表中にクリックで再生・一時停止（再生バーも出ます）。選ぶと「再生」タブ：プレビュー、トリミング、フェードイン・フェードアウト、音量、開始（自動／クリック時／一連のクリック動作）、スライド切り替え後も再生、停止するまで繰り返す、再生中のアイコンを隠す、再生が終了したら巻き戻す、ビデオの全画面再生・再生中のみ表示、スタイルなし・バックグラウンドで再生。開始の設定はアニメーション ウィンドウの「スライドの自動の動き」にも並びます。音声も書き出したHTMLに入ります。
- **描画**：描画タブのペン・蛍光ペンで、スライドにマウス・タッチ・ペンで書けます（続けて書いた線は1つのインクにまとまります）。消しゴムはなぞった線を消し、投げ縄は囲んだ線を選んで動かせます。「インクを図形に変換」をオンにすると、書いた線が直線・四角形・楕円・三角形などの図形になります（選んだインクはすぐ変換）。「描画で再生」で書いた順に再生し、「発表で再生」で発表中に書かれていくアニメーションを付けます。色はSEJの色です。
- **ズーム・カメオ・数式**：挿入 → ズームで、サマリー ズーム（選んだスライドの縮小版を並べた新しいスライド）・スライド ズーム・セクション ズームを入れます。発表でクリックするとそのスライドへ移り、終わると戻ります（ズーム タブで「ズームに戻る」・ズーム先の変更）。カメオは発表中にカメラの映像を丸く映します。数式はTeXで書き（分数・ルート・Σ・上付き・下付き）、ダブルクリックで直せます。ワードアートはSEJの文字色の見出し向きの文字、スライド番号・総数・日付は自動で更新されるフィールドです。
- **スライド ショーの設定・目的別スライド ショー**：自動プレゼンテーション（クリックでは進まず、タイミングのないスライドは決めた秒数で進んで繰り返す）、Escキーまで繰り返す、発表するスライドの範囲・目的別スライド ショー、アニメーションを表示しない、タイミングを使う／クリックで進む、ペンの色、常に字幕を使用。目的別スライド ショーは名前を付けてスライドと順番を選び、メニューから発表できます。設定は資料に保存され、書き出したHTMLにも入ります。
- **アクセシビリティ**：校閲 →「アクセシビリティ チェック」で作業ウィンドウに一覧が出ます（エラー・警告・ヒント、番号を押すとその場所へ）。代替テキストのない図・グラフ・SmartArt・アイコン・インク・ビデオ・塗りのある図形、タイトルのないスライド、見出し行のない表、「こちら」などの行き先が分からないリンク、読みにくい文字の色、見た目と違う読み取り順序、同じタイトルのスライドを見つけ、「説明を追加」「装飾用にする」「タイトルを付ける」「見出し行をオン」「見た目の順にそろえる」で直せます。下の「読み取り順序」で画面読み上げの順を↑↓で変えられます（重なり順は変わりません）。部品の右クリック・校閲 →「代替テキスト」でも説明を付けられます。代替テキストと読み取り順序は書き出したHTMLの読み上げにも使われます。
- **印刷**：ファイル →「PDF・印刷」（⌘P）で、フル ページ サイズのスライド・ノート・アウトライン・配布資料（1・2・3・4・6・9スライド、横・縦の順、3スライドはメモ欄付き）を選び、範囲（すべて・現在・「1,3,5-8」）、非表示スライド、カラー・グレースケール・単純白黒、枠、ヘッダー・日付・ページ番号・フッターを指定して、プレビューを見てから印刷・PDFに保存します。設定は次回も同じです。
- **情報・ドキュメント検査**：ファイル →「情報」で作成者・件名・キーワード・分類・会社・状態・コメントを資料に保存し（HTML出力のメタ情報にも入ります）、スライド・部品・アニメーション・コメント・文字数などの統計を見られます。ドキュメント検査で、渡す前にコメント・ノート・非表示スライド・非表示の部品・スライドの外にある部品・プロパティをまとめて削除できます（⌘Zで戻せます）。
- **表記ゆれ・スペル チェック**：校閲 →「表記ゆれチェック」で、全角・半角（ＡＩ／AI）、長音（ユーザ／ユーザー）、半角カナ、送り仮名（行う／行なう、打合せ／打ち合わせ）のゆれを見つけ、使う表記を選んで資料全体を統一します（言葉の一部は変えません）。「スペル チェック」をオンにすると、入力中の文字にブラウザの辞書で赤い波線が出ます。
- **スライド ショーの記録**：スライド ショー →「記録」で、発表しながらマイクでナレーションを録ります。終わると、スライドごとのナレーション（スライドが出ると流れる、見えない音声）とタイミング（自動で切り替え）として保存できます。「ナレーションの再生」で発表時に流すかを選び、「クリア」でこのスライド・すべてのタイミングとナレーションを消せます。
- **リハーサル**：スライド ショータブの「リハーサル」で、最初から発表して1枚ずつの時間を計ります（左上に時計）。終わると、その時間で自動的に切り替えるよう保存できます（⌘Zで戻せます）。
- **開発タブ**：「スライドのJSON」で、表示中のスライドのデータ（レイアウト・文字・部品・アニメーション・インタラクション）を直して「適用」（形式を確かめてから反映、⌘Zで戻せます）。「HTMLを表示」でエンジンが描くHTMLを見る・コピー。資料のJSONの保存・読み込み、HTML出力、PDFもここから。⌘H でも検索・置換。
- **一覧・構成のとき**もリボンは出たままで、スライド単位の操作（新しいスライド・デザイン・画面切り替え・スライド ショー・校閲・表示）が使えます。

- **マウス**：ドラッグで移動、四隅と辺でサイズ、上の丸で回転、黄色の点で形の調整（角の丸み・矢印の太さ・吹き出しの向きなど）。Shiftで縦横比を保つ・まっすぐ動かす・15°ずつ回す、⌘（Ctrl）を押しながらドラッグでコピー、Altで吸着を外す。背景をドラッグすると囲んだものを選べます。
- **文字**：図形をダブルクリック（または選んで Enter・そのまま入力）で、図形の中に文字を書けます。選んだ文字だけの太字・色・サイズ、図形全体の書式のどちらも変えられます。テキストボックスは文字に合わせて伸び、図形は「はみ出す場合だけ自動調整」も選べます。
- **吸着**：ほかの図形の端・中央・等間隔、スライドの中央とSEJの本文の領域にピタッと合い、合った線が出ます。線の端を図形の点（上下左右の中央）に近づけるとつながり、図形を動かしても線がついてきます。
- **書式パネル**：右の「書式」タブで、塗り・線・文字・図・サイズと位置（cm・°）・透明度・配置・リンク・動作を細かく設定できます。下の「選択ウィンドウ」で、すべてのオブジェクトの表示・非表示・順番（ドラッグ）・名前を変えられます。
- **リボンの幅**：ウィンドウが狭いときは、PowerPointと同じように右のグループから、ボタンの文字を省き、グループを1つのボタンにまとめます（押すと中身が開きます）。タブをダブルクリックするとリボンを折りたためます。
- **SEJのきまり**：色の一覧はSEJの文字色（黒・濃紺・グレー）と面の色（淡青・グレー・淡茶）だけです。ほかの色も選べますが「チェック」にSEJブランドの指摘として出て、「移動」でその図形を選んだ状態にします。白抜き文字・濃紺の面の上の文字・影・色の付いた面の枠線、SEJのマーク（ロゴ・秘（B）・社内限り など）と重なる配置も指摘します。マスターはいつも図形より前に描かれ、隠れません。
- **図形に変換**：AIが作ったレイアウトのスライドを、見た目はそのままで図形・テキストボックス・線・画像・アイコン・グラフ・表に分けます（「ホーム」→「図形に変換」か、スライドの何もないところを右クリック）。スライドは白紙になり、タイトル・キーメッセージ・ノート・出所は残ります。項目ごとの部品はグループになり、「クリックで順番に」などの出し方はアニメーションに、「詳しく」のカードと深掘りページもその項目の部品から開きます。色はSEJの色に（混ぜた淡い色は元の色と透明度に）合わせます。表紙・章扉・クロージング・全面写真・ひと言メッセージは変換しません。⌘Zで元に戻せます。
- **頂点の編集**：曲線・フリーフォームで描いた図形は、右クリック →「頂点の編集」で点を動かす・足す（辺をダブルクリック）・消す（Delete）ことができます。
- **AIとの関係**：手で置いた図形・文字・画像は、AIに頼んで直しても消えません。AIにはスライドごとの「自由配置」の要約（部品の数と中の文字）だけを伝え、AIはそれを書き換えません。AIは白紙のスライドを作りません。
- **発表と書き出し**：発表・HTML出力・PDFにもそのまま出ます。リンク・動作を付けた図形は、発表中にクリックするとそのスライドへ移る・Webページを開きます。

## PowerPointを見た目どおりに取り込む

作ったPowerPointをHTMLにして動きを付けたいときに使います。「作成」→「既存の資料を取り込む」で .pptx を選ぶと、取り込み方を聞かれます。

| 取り込み方 | できあがり |
|---|---|
| 見た目どおりに取り込む（おすすめ） | 1枚ずつ白紙のスライドに、元と同じ位置・大きさ・色・文字で部品を並べます。図形（回転・反転・形の調整）、テキストボックス（1文字ずつのサイズ・太字・斜体・下線・色・リンク、行間・段落の間隔、箇条書きと段落番号、余白・上下の配置・折り返し・縦書き・自動調整）、プレースホルダー（レイアウト・マスターから受け継ぐ位置と書式）、画像（トリミング）、線とコネクタ（矢印・カギ線・曲線）、表（セルの塗り・罫線・結合、表のスタイル）、グラフ（下記）、SmartArt、グループ、背景、ノート。アニメーション（開始・強調・終了・軌跡、クリック時／同時／後、継続時間・遅延）と画面切り替えも引き継ぎます |
| HTMLレイアウトに組み直す | 文章・表・グラフ・ノートを読み取り、スタジオのレイアウトに組み直します（PDF・Wordはいつもこちら）。AIでブラッシュアップして作り直すときに |

- **グラフ**：棒（縦・横・集合・積み上げ・100%）・折れ線（マーカー・平滑線）・面・円・ドーナツ・複合を、PowerPointの書式のまま描きます。系列と要素ごとの色、要素の間隔、線の太さとマーカー、データラベル（表示形式・位置・フォント・要素ごとのラベルの文字）、軸（表示・最小値と最大値・目盛りの間隔・反転・表示形式）、目盛線、凡例、プロットエリアの位置。データは「グラフのデザイン」→「データの編集」で直せます。種類を変えると色だけ残してその種類の描き方に、「書式をリセット」でスタジオのグラフの描き方になります。
- **元資料のマスター**：SEJの資料もほかのテンプレートの資料も、元のロゴ・緑線・秘（B）・背景・飾りを個別の部品として保持します。スタジオ側のマスターは重ねず、元の配色にSEJブランド検査も掛けません。4:3の資料は16:9の画面の中央に置き、元ページの外を表示時に隠します。
- **編集データに残すもの**：非表示スライドと非表示図形、ページ外の部品、元画像のバイト列、線形グラデーション、外側の影、元フォント名。非表示スライドは発表の順番から除外します。取り込みは最大500枚です。
- **再現に制限があるもの**：EMF・WMF、3Dや一部のパターン塗り・特殊効果。元フォントが端末にない場合は代替フォントで表示します。再現できない要素の件数は取り込み後に知らせます。原本との照合が必要です。
- 取り込んだ部品は、ほかの部品と同じように動かして直せます。メッセージの「アニメーションを編集」（またはリボン「アニメーション」）で引き継いだアニメーションを直して動きを足し、「✦ HTMLの動きをおまかせで付ける」「自分で付ける」でHTMLならではの動き（下の「HTMLならではの動きとインタラクション」）を付けて、発表・HTML出力で使います。

## アニメーション（PowerPoint風）

手で置いた図形・文字・画像と、レイアウトの部品（タイトル・キーメッセージ・本文の項目）に、PowerPointと同じ考え方のアニメーションを付けられます。発表・動きを確認・HTML出力で同じように動きます。

| 種類 | 効果 |
|---|---|
| 開始（緑） | アピール・フェード・スライドイン・フロートイン・ワイプ・スプリット・図形（円・ボックス・ひし形・プラス）・ホイール・ランダムストライプ・ズーム・ターン・バウンド・グローとターン・ストレッチ・ライズアップ・スピナー・ピンウィール・エクスパンド |
| 強調（黄） | パルス・カラーパルス・シーソー・スピン・拡大/収縮・透過性・塗りつぶしの色・線の色・フォントの色・明るく・暗く・不飽和・太字フラッシュ・点滅・ウェーブ・下線 |
| 終了（赤） | 開始の逆（クリア・フェード・スライドアウト・フロートアウト・…・シュリンクとターン・折りたたみ・シンクダウン・コントラクト） |
| アニメーションの軌跡 | 直線（上下左右・斜め）・円弧・ターン・円・正方形・三角形・ハート・ループ・波線・ジグザグ・バウンド・ユーザー設定パス（クリックで点、ドラッグで自由に、ダブルクリックで終わり） |
| メディア | 動画・オーディオ・Lottieの再生・一時停止・停止 |

- **リボン「アニメーション」**：プレビュー（自動プレビューのオン・オフ）、効果のギャラリー（選んだ図形のアニメーションを置き換え）、効果のオプション（方向・量・色・テキストの動作・パスの反転/閉じる/曲線/描き直す）、アニメーションの追加、アニメーション ウィンドウ、トリガー、アニメーションのコピー/貼り付け、開始・継続時間・遅延、順番を前に/後に、削除。
- **アニメーション ウィンドウ**（右の「アニメーション」タブ）：クリックの番号、開始のしかた、効果の色、対象の名前とタイミングの棒。ドラッグで並べ替え（トリガーの列へ移すとトリガーで再生）、▾のメニュー、すべて再生・選択から再生。下の欄で効果・方向・量・色・テキストの動作・開始・継続時間（速さ）・遅延・繰り返し（回数・次のクリックまで・スライドの最後まで）・巻き戻し・往復・滑らかさ（バウンド終了を含む）・トリガー・パスの操作。
- **スライド上**：アニメーションのタブかウィンドウを開いているとき、部品の左上にクリックの番号（0はスライドが出たとき、⚡はトリガー）。軌跡は始点（緑）・終点（赤）・終わりの位置の点線が出て、点をドラッグして形を変えられます。
- **発表**：レイアウトの「中身の出し方」のクリックのあとに、アニメーションのクリックが続きます（本文の項目にアニメーションを付けると、そのスライドはアニメーションの順番だけで出ます）。再生中のクリックは、まず再生を終わらせます。トリガーの図形はクリックでき、スライドは進みません。
- **画面切り替え**（リボン「画面切り替え」）：このスライドへの切り替え（資料の設定に従う・フェード・スライド・ズーム・モーフ・ワイプ・サークル・押し上げ・めくる・奥へ・ブラインド・幕・なし）、期間（秒）、自動的に切り替え（秒。残りのクリックも順に再生してから次へ）、すべてに適用、プレビュー。
- 図形をコピー・複製すると、そのアニメーションも付いてきます。図形を消すと、そのアニメーションも消えます。グループを解除すると、グループのアニメーションは各部品のアニメーションになります。

## HTMLならではの動きとインタラクション

PowerPointにはない、HTMLならではの動きと操作です。手で置いた部品にも、PowerPointから取り込んだ部品にも付けられ、発表・HTML出力でそのまま動きます。

| 種類 | 選べるもの | 付け方 |
|---|---|---|
| マウスを乗せたとき | 浮き上がる・拡大する・光る・3Dで傾く・ほかを薄くする、説明（ツールチップ） | リボン「インタラクション」 |
| クリックしたとき | 詳細を開く（カード、内訳・出所があれば右からのパネル。スライドは進まない）・拡大して見せる・裏返す（カードの裏に答え）・ほかの部品を表示・非表示（「1つだけ表示」でタブのように）・スポットライトを当てる | リボン「インタラクション」 |
| ずっと動く | ふわふわ浮く・鼓動する・ゆらゆら揺れる・回り続ける・光が走る・弾む | リボン「インタラクション」 |
| HTMLの効果（アニメーション） | 開始：タイプライター・デコード・マスクから立ち上がる・ぼかしから・線を描く・カウントアップ（数字が数え上がる）・グラフが伸びる／強調：光が走る・波紋・マーカーを引く・スポットライト | リボン「アニメーション」→「HTMLの効果」。ギャラリーの「HTMLならでは」の欄（青緑の印）。クリック・同時・後・トリガーもPowerPointの効果と同じ |
| PowerPointのグラフ | マウスを乗せると値の吹き出しが出て、ほかの要素が薄くなる。凡例をクリックすると系列を隠す・戻す | 取り込むだけで動く |

- **自動で付く**：PowerPointを「見た目どおり」に取り込むと、HTMLの動き（おまかせと同じもの）を自動で付けます。メッセージバーで何を付けたかを知らせ、「▶ 動きを見る」「アニメーションを編集」「元に戻す」（PowerPointのままに戻す）「次から自動にしない」を選べます。リボン「インタラクション」の「取り込み時に自動」でオン・オフします。PowerPointのアニメーションは消さず、順番もそのままです。
- **動きはすべてアニメーション ウィンドウで直せる**：右の「アニメーション」タブに、そのスライドで動くものを起きる順にまとめて並べます。「スライドの自動の動き」（画面切り替え・登場のしかた・中身の出し方・タイトルの動き・背景の動き・強調。おまかせは資料・レイアウトの設定）をその場で選び直し、「アニメーション」（クリック・同時・後・トリガー、HTMLの効果も）を並べ替え・設定し、「インタラクション（HTML）」の部品ごとの設定（マウス・説明・クリック・ずっと動く）を×で外す・名前を押してリボンで変える、ができます。見た目どおりに取り込んだページは元の見た目を守るため、レイアウトの自動の動きは付けず、画面切り替えだけを選べます。
- **おまかせ**：リボン「インタラクション」→「HTMLの動きを付ける」（このスライド／すべてのスライド）で、部品の種類に合わせて付けます。タイトルはマスクから立ち上がり、グラフは軸から伸び、大きな数字は数え上がり、線は描かれ、色の付いたカードはマウスで浮き上がり、写真はクリックで拡大します。スライドにもとからあるアニメーション・動作・反応はそのまま残し、何度押しても重ねません。ロゴ・秘（B）・スローガンのように同じ位置で何枚にも出てくる部品（テンプレートの飾り）と非表示のスライドには付けません。⌘Zで1回で元に戻せます。
- **PowerPointから取り込んだ資料**：取り込んだあとのメッセージの「✦ HTMLの動きをおまかせで付ける」で、資料全体に付けます。「自分で付ける」でリボン「インタラクション」が開きます。
- **スライド上**：リボン「インタラクション」を開いているとき、付けた部品の右上に印（反応・クリック・ずっと動く）が出ます。「▶ 試す」でそのスライドを発表して確かめられます。
- **発表**：クリックできる部品は、ページが組み上がったときに一度だけ光って知らせます。拡大・スポットライトはもう一度クリック（またはEsc）で戻ります。「詳細を開く」「裏返す」「表示・非表示」はスライドを進めません。
- OSで「視差効果を減らす」を設定している人には、ずっと動く動きを止め、マウスの反応と裏返しは動かさずにすぐ切り替えます（クリックの操作は使えます）。

## 動く資料（クリックで確かめる）

会議で「その内訳は？」と聞かれたときに、資料が答えられるようにする仕組みです。動かし方はセンスではなく、見出しが言いたいことの構造で決めます。1ページの操作は1つだけです。

| 構造 | 付ける操作 | 作り方 |
|---|---|---|
| 結論と根拠 | 押すと根拠が出る | 「編集」タブの「クリックで開く詳細」で、項目かキーメッセージを選び「根拠パネルにする」に内訳（1行に「ラベル,値」）・出所・前提を入れる。発表中は右から根拠パネルが開く（内訳・出所と前提のタブ） |
| 切り口 | 切り替えると並び替わる | グラフの種類「順位（切り口で並び替わる）」。CSVの1行目に切り口を並べる（例：`業種,全体,一次請け,二次請け`）。主役の項目は色で目立たせる |
| 差分 | 形が変わり、差が残る | グラフの種類「前後の差」。CSVは `ラベル,前の値,後の値`。棒が前から後へ縮み、減った分が点線で残る |
| 原因と結果 | 条件を動かすと計算し直す | レイアウト「試算（条件を動かす）」。条件（最大3つ。式では上から a・b・c）と計算式（例：`a × b × c ÷ 100`）、比べる値（目標など）。式は画面に出る |
| 不足と打ち手 | オン・オフで不足が埋まる | レイアウト「不足と打ち手」。目標・現状・打ち手（上乗せ量）。発表中はクリックのたびに打ち手が1つずつオンになり、打ち手をクリックしてオン・オフもできる |
| 流れと時間 | 順に組み上がる | 工程・計画は「クリックで」。ガントチャートは「いま」の位置を入れると赤い線が出る |

- 本文スライドには「出所」を入れられます。ページ下に出て、グラフにマウスを乗せたときの吹き出しにも出ます。
- 発表中、ページが組み上がると、押せる所・動かせる所を一度だけ輪で知らせます。
- 「雛形から作る」→「動く資料（クリックで確かめる）」に、6つの構造をすべて使った記入例があります。
- AIに「クリックで確かめられるようにして」「内訳を根拠パネルで」「条件を変えて試算できるように」「打ち手で不足が埋まるのを見せたい」と頼むと、構造に合う操作を1つ付けた提案が届きます。資料を新しく作るときも、数字と出所がある本文スライドに付けます。

## モーショングラフィック

動きは「注目を集める」「場面が変わったことを伝える」ために使います。既定では、表紙・章扉・ひと言メッセージ・最後のスライドの大きな文字が「マスクから立ち上がる」動きで現れ、アイコン・線・マーカーが描かれるように出ます。

| 種類 | 選べるもの | どこに効くか |
|---|---|---|
| 大きな文字の動き（`kinetic`） | マスクから立ち上がる / ことばごとに浮かぶ / 1文字ずつ弾む / タイプライター / デコード（文字が入れ替わって決まる）/ 波打って並ぶ / 手前から迫る / 1文字ずつめくれる / 横から滑り込む | 表紙・章扉・全面写真・ひと言・最後のスライド。本文スライドで選ぶとタイトルが動く |
| 背景の動き（`backdrop`） | 粒子が昇る / 波が流れる / グリッドと走査線 / 軌道を回る / 色がゆらぐ / 線を光が流れる / 図形が漂う / 紙吹雪が舞う / ネットワークがつながる / 波紋が広がる / 星がまたたく / 光の筋が回る | 資料全体の設定は表紙・章扉・ひと言・最後のスライドに。1枚ずつなら本文スライドにも（薄く表示） |
| 強調の見せ方（`emphasis`） | マーカー / 下線 / 手書きの丸 / 枠 / 光らせる / 色だけ | `**語句**` で囲んだ語句。「線を描く」がオンなら、その印が描かれるように現れる |
| 登場のしかた（`entrance`） | 下から浮かぶ / ふわっと / ぼかしから / 弾むように / 左から滑り込む / 手前から迫る / めくれる / 幕が開く / 弾んで落ちてくる | スライドの見出しと中身が現れるとき。資料全体でも1枚ずつでも |
| 線を描く（`draw`） | オン・オフ | アイコン・ロジックツリーの線・サイクルの弧・組織図の線・強調の印が描かれる |
| 切り替え（`transition`） | ワイプ（アクセント色の帯が横切る）/ サークル（クリックした所から円が広がる）/ 押し上げ / めくる（カードのように裏返る）/ 奥へ（飛び込む）/ ブラインド / 幕（中央から開く） | スライドの移り変わり。1枚ごとに選ぶと、そのスライドに入るとき（戻るときは出るとき）だけ変わる |
| 順に注目（`animation: spotlight`） | 全部見せたまま、クリックのたびに1項目を強調し、ほかを薄くする | 比較・選択肢・論点を1つずつ話すスライド |
| Lottieアニメーション | After EffectsやLottieFilesで作られたアニメーション | 「写真・動画・アニメーション」→「アニメーション」でJSONを入れる。発表中に再生、編集画面では途中の1コマ |

- AIに「表紙と章扉の背景を動かして」「この1枚の文字をタイプライターで」「強調を手書きの丸にして」「カードを1つずつ注目させて」「章扉の切り替えを幕にして」と頼むと、提案として届きます。資料を新しく作るときは、表紙・章扉・締めにSEJテンプレートの波紋（同心円）が入り、ほかの背景は付けません。
- LottieFilesのアニメーションは「Lottie JSON」でダウンロードしたファイルか、`https://lottie.host/…` のURLを使います（「.lottie」形式は使えません）。取り込んだアニメーションはこのブラウザに保存され、HTML出力にも入ります。
- OSで「視差効果を減らす」を設定している人には、動きを止めて最初から全部見せます。

## デザイン

スタジオの資料は**SEJテンプレートだけ**です。スライドエンジン（`public/engine/`）には、ベースの HTML Slide Studio から受け継いだ8つのテーマ（クリア・ミッドナイト・エディトリアル・モノ・フォレスト・サンセット・オーロラ・生成り）も残っていますが、どのレイアウトでも崩れないかを確かめる撮影テスト（`npm run qa`）で使うだけで、スタジオ・AI・書き出しでは使いません。

デザインの考え方は [docs/design-system.md](docs/design-system.md) にまとめています。

## 資料のデータ（JSON）

資料は `{ title, purpose, audience, theme, accent, transition, motion, memo, slides }` のJSONです。`theme` はいつも `sej`（ほかの値のJSONもスタジオで開くと `sej` になり、`accent` は外れます）。`transition` は `none` `fade` `slide` `zoom` `morph` `wipe` `circle` `push` `flip` `dive` `blinds` `curtain`、`motion` は `{ entrance, hover, numbers, ambient, kinetic, backdrop, emphasis, draw }`（`entrance` は `rise` `fade` `blur` `pop` `slide` `zoom` `flip` `wipe` `drop` `none`、`hover` は `lift` `focus` `tilt` `glow` `zoom` `none`、`emphasis` は `marker` `underline` `circle` `box` `glow` `none`。`kinetic` と `backdrop` は表紙・章扉などの既定）。各スライドは `type`（45種類。`blank` は白紙）とレイアウトごとの項目に加えて、次を持てます。

| 項目 | 内容 |
|---|---|
| `takeaway` | キーメッセージ（`**語句**` でその語句を強調） |
| `animation` | 中身の出し方：`auto`（レイアウトに合わせる）/ `none` / `fade` / `cascade` / `click` / `spotlight`（順に注目） |
| `kinetic` | 大きな文字の動き：`auto`（資料の設定）/ `none` / `mask` / `words` / `chars` / `type` / `scramble` / `wave` / `zoom` / `flip` / `slide` |
| `backdrop` | 背景の動き：`auto`（資料の設定）/ `none` / `particles` / `waves` / `grid` / `orbits` / `gradient` / `lines` / `shapes` / `confetti` / `network` / `ripple` / `stars` / `rays` |
| `entrance` / `emphasis` / `transition` | この1枚だけの登場のしかた・強調の見せ方・このスライドへの切り替え（`auto` は資料の設定） |
| `details` | クリックで開く詳細：`[{ target: "items[0]", title, text, rows, source, note }]`。`target` が `"takeaway"` ならキーメッセージの根拠。`rows`（`[{ label, value }]`）・`source`・`note` のどれかがあると根拠パネルになる |
| `source` | 出所（ページ下とグラフの吹き出しに表示） |
| `drillOf` | 深掘りページにする：直前の本編スライドの項目（`"items[1]"` など）。そのスライドの直後に置き、本編の番号・流れには数えない |
| `visualAsset` / `photoMotion` | 内蔵写真 / 写真の動き（`zoom` `pan` `float` `parallax` `reveal` `drift` `tilt`） |
| `image`（グラフ） | `chartType` に加えて `rank`（`data.views: [{ label, items }]`・`highlight`・`unit`）、`shift`（`data.items: [{ label, before, value }]`・`beforeLabel`・`afterLabel`・`unit`） |
| `simulator` の項目 | `inputs: [{ label, value, min, max, step, unit }]`（上から a・b・c）、`formula`（a・b・c と ＋ − × ÷ ( ) と数字だけ。コードとしては実行しない）、`resultLabel`、`resultUnit`、`digits`、`compareLabel`、`compareValue` |
| `gap` の項目 | `unit`、`targetLabel`・`target`、`currentLabel`・`current`、`measures: [{ title, value, desc }]` |
| `gantt` の `now` | 「いま」の位置（1.5＝2つ目の期間の真ん中） |
| `media` | ユーザーが入れた写真・動画・アニメーション：`{ src, kind, fit, autoplay, loop, muted, placement }`。`kind` は `image` `video` `lottie`、`src` はURL・YouTube・`idb:…`（このブラウザに保存したファイル） |
| `notes` | スピーカーノート |

| `elements` | 手で置いた部品：`[{ id, kind, x, y, w, h, rot, … }]`（1920×1080の座標）。`kind` は `shape`（`shape` に図形の種類、`adj` に形の調整。`shape: "custom"` は手で描いた形で `path: { pts: [[0..1, 0..1], …], closed, curve }`）・`text`・`image`（`crop: { l, t, r, b }` はトリミングの割合）・`line`（`x1,y1,x2,y2` か `from`/`to` で図形につなぐ、`head`/`tail` に矢印の形、`route`）・`icon`・`video`・`lottie`・`table`（`cells: [[{ text, fill, color, bold, align, valign, rs, cs, merged, bt, br, bb, bl }]]`（`bt` などはセルの上下左右の罫線 `{ c, w }` か `"none"`）・`cols`・`rows`（幅と高さの割合）・`style`・`header` `banded` `firstCol` `lastRow`・`fs`）・`chart`（`chart: { type, labels, series: [{ name, values }], title, unit, style }`。`style` はPowerPointから取り込んだグラフの書式で、あるとPowerPointと同じ描き方になる：`dir`（`bar` は横棒）・`stack`・`gap`・`overlap`・`hole`・`angle`・`font`・`title`・`legend: { pos }`・`cat`/`val: { hide, reverse, min, max, step, format, line, grid, font }`・`plot: { x, y, w, h }`・`series: [{ kind, color, width, dash, smooth, marker: { s, z, at }, points: [{ i, color }], label: { val, pct, cat, ser, pos, format, font }, pointLabels: [{ i, …, runs }] }]`）。`item` は「図形に変換」で元になったレイアウトの項目（`"items[1]"`。その項目の詳細・深掘りページを開く）。文字は `text`（`p` `br` `b` `i` `u` `s` `sup` `sub` `span[style]` `ul` `ol` `li` だけのHTML。段落の `data-indent` はインデント、`data-bullet` は箇条書きの記号）、書式は `fill` `stroke` `strokeW` `dash` `font` `fs` `color` `bold` `align` `valign` `pad` `autofit` `vertical` など、`group` `locked` `hidden` `name` `action`（`{ type: "slide", to: sid }`・`{ type: "url", href }`・`next` `prev` `first` `last` `end`、HTMLならではの `{ type: "popup", title, text, rows: [{ label, value }], source }`・`{ type: "zoom" }`・`{ type: "spot" }`・`{ type: "flip", back, fill }`・`{ type: "reveal", targets: [部品のID], only }`）、`hover`（`lift` `zoom` `glow` `tilt` `focus`）、`tip`（マウスを乗せたときの説明）、`loop`（`float` `pulse` `sway` `spin` `shine` `bounce`） |
| `sid` | スライドの固定のID（リンク・動作の行き先） |
| `hidden` / `section` / `comments` | 非表示スライド（発表では飛ばす）／ここから始まるセクションの名前／コメント `[{ id, text, at, by, uid, anchor, done, doneBy, edited, replies: [{ id, text, at, by, uid, edited }] }]`（校閲。`by` は書いた人、`anchor` はピン留めした部品。発表・書き出しには出ない） |
| `hideTitle` / `master` | 白紙のスライドで、スタジオのタイトルを出さない（PowerPointから取り込んだスライドは自分のタイトルの枠を持つ）／SEJのマスター（`title` は表紙のマスター、既定は `content`） |
| `timeline` | アニメーション：`[{ id, el, cls, fx, start, dur, delay, dir, amount, color, by, repeat, rewind, autoReverse, ease, trigger, path }]`。`el` は部品のID・`grp:グループ`・`@title`・`@takeaway`・`@g0`（本文の項目）。`cls` は `in` `em` `out` `path` `media`、`start` は `click` `with` `after`、`dur`・`delay` はミリ秒、`path` は `{ pts: [[0,0],…], closed, curve }`（部品の中心からのpx）。HTMLの効果は `fx` が `typewriter` `decode` `maskRise` `blurIn` `draw` `countUp` `chartGrow`（開始）・`shine` `ripple` `marker` `spotlight`（強調）で、`decode` `countUp` `chartGrow` には終了がなく、`by`（文字ごと）は使わない |
| `transitionDur` / `advance` | 画面切り替えの期間（ミリ秒）／自動的に切り替えるまでの秒数 |

資料には、ほかに `guides`（表示 → ガイドで置いたガイド：`{ x: [px…], y: [px…] }`、1920×1080の座標）を持てます。

`media`・`elements`・`timeline`・`sid`・`transitionDur`・`advance`・`hideTitle`・`master`・`hidden`・`section`・`comments` はユーザーだけが設定する項目で、AIには中身を見せず（`elements` と `timeline` は要約だけ）、AIの変更でも消えません。
