# デザインの考え方

HTML Slide Studio のスライドは、会社のテンプレートを使わずにゼロから設計しています。目指したのは「画面共有で遠くからでも読める」「動きが意味を持つ」「どのテーマでも崩れない」の3つです。

## 1枚の原則

- **1枚1メッセージ**。タイトルは論点（何の話か）、キーメッセージ（takeaway）は結論の一文。上からキーメッセージだけ読めば話が通じるようにします。
- **強調は1〜2か所**。`**語句**` で囲んだ語句だけがアクセント色＋マーカーになります。色を増やすのではなく、1か所を目立たせます。
- **数字は大きく**。KPI・数値比較は数字を主役にし、単位は小さく添えます。発表中は数字がカウントアップします。
- **箱より罫線と余白**。カードを並べるより、罫線・番号・余白で区切るほうが画面共有で締まって見えます。
- **書ききれない根拠は「クリックで開く詳細」へ**。スライドには結論と要点だけを置き、聞かれたら開きます。
- **文字が収まらないときは、まず文を短く**。エンジンは本文を最大30%まで自動で縮めますが、それでも収まらない箇所は赤い破線で知らせ、AIが短く言い換えます。

## 資料全体の変化（見た目のグループ）

レイアウトの名前が違っても、画面では同じ形に見えるものがあります。タイムライン・プロセス・ロードマップ・レーン図は、どれも「横に線が通り、点や箱が並ぶ」スライドです。そこで単調さはレイアウトの種類ではなく、次の「見た目のグループ」で判断します（定義は `public/layout-looks.mjs`。AIへの指示・自動チェック・スタジオの「チェック」が同じ定義を使います）。

| グループ | レイアウト |
|---|---|
| 横に並ぶ流れ | プロセス・タイムライン・ロードマップ・フローチャート・ガント・レーン図 |
| 縦に並ぶ行 | 本文・工程リスト・エグゼクティブサマリー・要点カード・FAQ・チェック |
| カードの並び | カード・見出しカード・2×2・2列・3列まとめ・SWOT |
| 左右の対比 | 対比・前後・数値比較 |
| 数字・グラフ | KPI・ダッシュボード・ウォーターフォール・グラフ |
| 図形 | サイクル・ピラミッド・ファネル・トライアングル・ベン図・ステップアップ・ロジックツリー・組織図・マトリクス |
| 表 | 表 |
| 大きな一文・写真 | ステートメント・全面写真・引用（写真付きの本文もここ） |

- 表紙・アジェンダ・章扉・最後のスライドは数えません。
- **同じグループは本文の4枚に1枚まで**（本文6枚なら2枚、10枚なら3枚）。流れ・行・カード・対比は**隣り合わせない**。図形や数字は1枚ごとに形が違うので続いてもかまいません。
- 本文が6枚以上なら**4グループ以上**を使います。
- 横に並ぶ流れは、順番や時期が本当にあるときだけ。時期のない「やること・備え」はカードやチェック、「層・段階」はピラミッドやステップアップ、「関係」はベン図やトライアングルにします。
- AIの骨子と、骨子なしで作った資料がこの決まりに合わないときは、AIに自動でレイアウトを選び直させます（骨子は2回まで、資料は1回）。ユーザーが骨子で選んだレイアウトはそのまま使います。

## キャンバスと文字

スライドは 1920×1080 の固定キャンバスに描き、表示する箱に合わせて拡大縮小します（スタジオ・発表・書き出しで同じ見た目）。

| 役割 | 大きさ | 備考 |
|---|---|---|
| タイトル | 60px | 2行まで。長いと自動で縮小（最小70%） |
| キーメッセージ | 31px | |
| 本文 | 30px | 本文・カード・表は `--fs` で一緒に縮む |
| カード見出し / 説明 | 34px / 26px | |
| 注記・ラベル | 22px | 字間を広げた小見出し |
| 余白 | 左右120px・上96px・下104px | フッターに資料名とページ番号 |

和文は見出し用（ゴシックまたは明朝）と本文用、数字用（欧文）の3書体をテーマごとに組み合わせています。数字は等幅ではなくプロポーショナルな lining 数字で、表の数値列だけ等幅（tabular）にして右ぞろえにします。

## テーマ

テーマはすべて同じ部品を使い、色・書体・角丸・影・いくつかの「そのテーマらしい細部」だけを変えます。

| テーマ | 背景 / 文字 / アクセント | 書体 | らしさ |
|---|---|---|---|
| クリア | 白 / 墨 / 深い青 | Zen Kaku Gothic New + Manrope | 同心円の表紙 |
| ミッドナイト | 濃紺 / 白 / 空色・琥珀 | Murecho + Sora | 回る点線の輪。画面共有で映える |
| エディトリアル | 生成りの白 / 黒 / 朱 | しっぽり明朝 + Cormorant Garamond の斜体数字 | 縦書きの章ラベル、細い罫 |
| モノ | 白 / 黒 / 信号の赤 | Noto Sans JP + Archivo | 太い黒罫、スイス風の格子 |
| フォレスト | 薄緑 / 深緑 / 緑・黄土 | Zen Maru Gothic + Figtree | 有機的な形 |
| サンセット | 暖かい白 / 茄子紺 / コーラル・琥珀 | M PLUS Rounded 1c + Outfit | 大きな円、明るい研修向け |
| オーロラ | 黒に近い紺 / 白 / ミント・桃 | Zen Kaku Gothic Antique + Plus Jakarta Sans | ゆっくり漂う光、ガラスの面、グラデーションの見出し |
| 生成り | 生成り / 焦茶 / 藍・弁柄 | 禅明朝 + Zen Kaku Gothic New | 青海波、筆の輪 |

アクセント色は資料全体で1色に差し替えられます（会社の色など）。グラフの1本目の色もそれに合わせて変わります。

## 深掘りページ

発表の流れは細く保ち、聞かれたら深く答えられるようにするための仕組みです。スライドの項目ごとに、本編の流れに入れない補足のページ（`drillOf`）を1枚ずつ用意できます。

- クリックできる項目には文字入りの印が付きます。「＋ 詳しく」は詳細カード、「↗ 深掘り」は深掘りページです。発表中は押せる範囲を点線で囲み（マウスを乗せると実線）、最初にそういうスライドが出たときに「〜の付いた項目はクリックできます」と一度だけ知らせます。図形と文字の行の両方で項目を表すレイアウト（ピラミッド・ファネル・ベン図）では、図形は輪郭で切り取られるため、印は文字の行に付けます。PDFには印を出しません。
- 発表中、深掘りページがある項目をクリックすると、その項目から広がるように深掘りページへ移ります。Esc・←、または最後まで進めると、元のスライドへ縮むように戻り、同じ場面（クリックで出した項目まで）から続けます。
- 深掘りページは本編の番号に数えません。ページには「02 ・ 深掘り」のように元のスライドの番号が付き、見出しの上に元のスライドの題名が出ます。
- 深掘りは1段階だけです（深掘りページからさらに深掘りはしない）。1つの項目に1枚まで。
- 深掘りページは元のスライドの直後に置き、並べ替え・削除・AIによる変更でも元のスライドと一緒に動きます。見た目の単調さのチェックには数えません。

## 動き

動きは「注目を1か所に集める」ためにだけ使います。常に動いているものは、写真のゆっくりした動きと背景の飾り（オフにできます）だけです。

| 動き | 使いどころ | 速さ |
|---|---|---|
| 登場（下から・ふわっと・ぼかし・はじける・滑り込む・迫る・めくれる・幕が開く・落ちてくる） | スライドが出たとき、見出し→中身の順。派手なもの（めくれる・落ちてくる）は印象づけたい1〜2枚に | 0.7〜0.9秒、減速カーブ（落ちてくるは最後に小さく弾む） |
| 順番に（cascade） | 並列の項目（カード・KPI・SWOTなど） | 0.17秒ずつずらす |
| クリックで（click） | 手順・時系列・分解（プロセス・ロードマップ・ロジックツリーなど）。説明しながら1つずつ | クリックごと |
| 順に注目（spotlight） | 比較・選択肢・論点。全体を見せたまま、話している1項目を少し大きくし、ほかを薄く・灰色にする | クリックごと（0.4秒で移る） |
| カウントアップ・グラフが伸びる | 数字・棒・線 | 1.1〜1.4秒 |
| マウスを乗せる | 浮き上がる／ほかを薄くする／マウスの位置に合わせて3Dで傾く／アクセント色の光で縁取る／少し大きくなる。グラフは値のツールチップ | すぐ |
| クリックで開く詳細 | 根拠・内訳・出典 | 0.45秒 |
| 写真 | ゆっくりズーム（16秒）・横に流す（18秒）・浮遊・マウスで奥行き・幕が開くように現れる・斜めに流す・ゆっくり傾く | ゆっくり（幕開けは1.2秒） |
| 切り替え | フェード・スライド・ズーム・モーフ（同じ見出しがつながって動く）・ワイプ（色の帯）・サークル（クリックした所から）・押し上げ・めくる（3D）・奥へ・ブラインド・幕（中央から）。章の変わり目だけ1枚ごとに変えてもよい | 0.5〜0.95秒 |
| 大きな文字（キネティック・タイポグラフィ） | 表紙・章扉・ひと言・最後の一文。マスクから立ち上がる（既定）・ことばごと・1文字ずつ・タイプライター・デコード・波打って並ぶ・手前から迫る・1文字ずつめくれる・横から滑り込む | 全体で0.9〜1.7秒に収まるよう1単位の間隔を自動で決める |
| 線を描く | アイコンの線・ロジックツリーの線・サイクルの弧・組織図の線、強調の印 | 0.8〜1.1秒 |
| 強調の見せ方 | `**語句**` の1か所。マーカー（既定）・下線・手書きの丸・枠・光・色だけ。丸と枠は時計回りに描かれる | 見出しや文字の動きが終わってから0.8〜1.6秒 |
| 背景の動き | 粒子・波・グリッド・軌道・グラデーション・流れる線・図形・紙吹雪（達成・お祝い）・ネットワーク（連携・組織）・波紋（波及・浸透）・星空（長期ビジョン）・光の筋（発表・幕開け）。「間」のスライド（表紙・章扉・ひと言・最後）に | 10〜40秒でゆっくり循環 |

- レイアウトごとに「おまかせ」の出し方が決まっていて（手順はクリック、並列は順番に、表紙や全面写真は静止）、1枚ずつ変えられます。
- 背景の動きは読む邪魔をしないよう、文字が始まる左側では薄く消え（軌道・流れる線・ネットワーク・波紋）、図形は右端と上下に寄せ、本文スライドでは半分の濃さにします。暗いテーマでは暖色が濁るので、2色目を紫に替えます。
- 文字の動きは、1文字ずつでも行頭に「、。」や小さい「っ」が来ない単位で分け、数字や英単語は途中で折り返しません。動き終わった文字は元の文と同じです。
- 背景・文字の動きは同じ資料の中で1〜2種類にそろえます（AIへの指示でも同じ決まりにしています）。
- OSで「視差効果を減らす」を設定している人には、動きを止めて最初から全部見せます。
- 編集画面では動かしません（「▶ 動きを確認」でその場で再生）。

## 動く資料（1ページ1操作）

資料の次の進化は作る速さではなく、見る人の体験で起きる、という考え方です。見出しの判断を、見る人が自分の手で確かめられるようにします。動きは思いつきで付けず、見出しが言いたいことの構造で1つに決めます。

| 構造 | 操作 | 見え方 |
|---|---|---|
| 結論と根拠 | 押すと根拠が出る | 右から幅720pxの根拠パネル。上から「どこの話か」→判断1〜2行→タブ（内訳／出所と前提）→小さな棒か表→出所。後ろは暗くし、×・Esc・後ろのクリックで閉じる |
| 切り口 | 切り替えると並び替わる | 切り口のボタンで全部の棒が0.75秒で並び替わる。主役は主役色、ほかは灰。値のない項目は最後に「データなし」 |
| 差分 | 形が変わり、差が残る | 棒が前の長さから後の長さへ1.3秒で変わり、前の長さが点線の枠で残る。差が最も大きい行だけ主役色 |
| 原因と結果 | 条件を動かすと計算し直す | 左に大きな結果（1ページに大きな数字は1つ）と比べる値との差、試算の棒、計算式。右にスライダー。「試算」と明記し、式を画面に出す |
| 不足と打ち手 | オン・オフで不足が埋まる | 現状（灰）＋打ち手（主役色の濃淡）を積み、目標までの不足を赤い点線で示す。届けば緑で「目標を上回る」 |
| 流れと時間 | 順に組み上がる | クリックで1段ずつ。計画には「いま」の赤い線 |

- 1ページの操作は1つだけ。見出しと関係ない動きは入れない。量を表す動きは値から計算する（手で長さを決めない）。
- 押せる所は見て分かるようにする：「＋ 詳しく／内訳／根拠」の印、点線の枠、ページが組み上がった直後に一度だけ輪で知らせる。
- 操作してもスライドは進まない。スライダーから手を離すと、→キーは次のスライドへ戻る。
- 動きを止めても資料として読めること：印刷・PDF・サムネイル・#static では、打ち手はすべてオン、試算は最初の値、順位は最初の切り口、前後の差は後の状態を出す。
- 出所はページ下とグラフの吹き出し、根拠パネルの3か所に出す。素材にない数字は置かない。

## グラフ

- 比較は棒、推移は折れ線、構成はドーナツ・積み上げ、内訳の増減はウォーターフォール。
- 強調は1本だけ（時系列なら最新、比較なら最大）をアクセント色にし、ほかは淡い色にします。
- 軸は1本。2つの単位を1つのグラフに重ねない。
- 系列が4本までは線の端に直接ラベルを付け、凡例を探させない。
- 発表中はマウスを乗せると値が出ます。

## 文章（AIへの指示にも使っている決まり）

- タイトルは30字以内、キーメッセージは60字以内。
- 素材にない数値や事実は作らない（AIの回答に素材にない数値があれば、自動で指摘・修正させます）。
- 箇条書きは「要素名：説明」の形で2〜5項目にすると、番号付きの大きな行になります。
- 1枚の本文は240字（表は320字）までを目安に。
